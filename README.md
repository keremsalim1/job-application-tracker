# Job Application Tracker

A simple web application to track job applications, built with React and Bootstrap 5.

## Features

- Add, list, edit and delete job applications (CRUD)
- Search by company name or position
- Filter by status and sort by date
- Status summary cards and color-coded badges
- Dark mode
- Data is stored in the browser's LocalStorage

## Technologies

- React (Vite)
- Bootstrap 5 & Bootstrap Icons
- LocalStorage

## Run Locally

npm install
npm run dev
